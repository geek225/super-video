================================================================================
          🎬 GUIDE D'INSTALLATION FACILE - SUPER VIDEO AI STUDIO 🎬
================================================================================
Bienvenue dans Super Video AI !
Ce guide vous explique pas à pas comment installer et utiliser ce logiciel sur
votre ordinateur en quelques minutes, même si vous n'avez aucune compétence
technique ou informatique.

Suivez simplement les 4 étapes ci-dessous.

================================================================================
ÉTAPE 1 : INSTALLER PYTHON SUR VOTRE ORDINATEUR (À faire 1 seule fois)
================================================================================
Pour fonctionner, le logiciel a juste besoin de Python (un outil gratuit et
officiel).

1. Allez sur le site officiel : https://www.python.org/downloads/
2. Cliquez sur le gros bouton jaune "Download Python" (version 3.10 ou supérieure).
3. Lancez le fichier téléchargé pour démarrer l'installation :

   ⚠️ ATTENTION SI VOUS ÊTES SUR WINDOWS (TRÈS IMPORTANT) :
   Dès la toute première fenêtre de l'installateur, avant de cliquer sur "Install",
   COCHEZ la case tout en bas :
   ☑️ "Add Python to PATH" (ou "Ajouter Python aux variables d'environnement").
   Ensuite, cliquez sur "Install Now".

   🍏 SI VOUS ÊTES SUR MAC :
   Suivez simplement les étapes de l'installateur jusqu'à "Installation réussie".

================================================================================
ÉTAPE 2 : DÉCOMPRESSER LE DOSSIER DU LOGICIEL
================================================================================
1. Si vous avez reçu le dossier sous forme de fichier compressé (.zip), faites
   un clic-droit dessus > "Extraire tout" (Windows) ou double-cliquez dessus (Mac).
2. Placez le dossier "super video" extrait à un endroit facile d'accès (par
   exemple sur votre Bureau).

================================================================================
ÉTAPE 3 : LANCER LE LOGICIEL (EN 1 SEUL CLIC)
================================================================================
Ouvrez le dossier "super video" et double-cliquez sur le fichier correspondant
à votre ordinateur :

🪟 VOUS ÊTES SUR WINDOWS :
-------------------------
👉 Double-cliquez sur le fichier :  lancer.bat
   - Une fenêtre noire va s'ouvrir et préparer automatiquement l'application.
   - Au premier lancement, cela peut prendre 1 à 2 minutes (le temps de tout
     préparer).
   - Votre navigateur Internet va s'ouvrir tout seul sur l'interface du studio.

🍏 VOUS ÊTES SUR MAC :
---------------------
👉 Double-cliquez sur le fichier :  lancer.command
   - Votre Mac peut parfois afficher un message de sécurité ("Fichier non approuvé").
     Si cela arrive, pas de panique, c'est normal pour un logiciel téléchargé :
     1. Faites un CLIC DROIT sur "lancer.command".
     2. Cliquez sur "Ouvrir".
     3. Confirmez en cliquant sur "Ouvrir" dans la petite fenêtre d'alerte.
   - Votre navigateur Internet s'ouvrira tout seul sur l'interface du studio.

================================================================================
ÉTAPE 4 : ACTIVER VOTRE CLÉ STUDIO ET COMMENCER
================================================================================
Dès que la page s'ouvre dans votre navigateur Internet :

1. En haut à droite de l'écran, cliquez sur le bouton : [ Clé Studio ]
2. Collez la clé d'activation qui vous a été fournie (elle commence par "sk-...").
3. Cliquez sur le bouton violet "Enregistrer la clé Studio".
4. C'est tout ! Un voyant vert s'allume : vous êtes prêt à animer vos visuels !

================================================================================
💡 COMMENT UTILISER LE STUDIO AU QUOTIDIEN
================================================================================
1. Glissez-déposez votre image ou affiche dans le grand cadre à gauche.
2. Choisissez votre mode :
   - "Motion Design Affiche" : Idéal pour animer des affiches sportives,
     des flyers ou des personnages sans jamais déformer les visages ou couper
     le haut de l'image.
   - "Vidéo Libre Cinéma" : Si vous souhaitez une création vidéo libre avec du texte.
3. Cochez les effets désirés (reflets or, confettis, projecteurs, zoom...).
4. Cliquez sur le gros bouton "Générer la Vidéo".
5. Une barre de progression vous indique l'avancement. Dès que c'est fini, la
   vidéo se lance automatiquement à l'écran et s'enregistre dans votre dossier :
   📁 super video/outputs/

================================================================================
🔄 COMMENT RECEVOIR LES MISES À JOUR
================================================================================
Les mises à jour se font de façon 100% automatique et transparente :
1. Une petite cloche en haut de l'écran vous prévient dès qu'une mise à jour
   est disponible.
2. Cliquez simplement sur "Mises à jour" puis "Installer la mise à jour".
3. Le logiciel télécharge les nouveautés et recharge la page tout seul.
4. Vos vidéos et votre clé Studio ne sont JAMAIS perdues lors d'une mise à jour.

================================================================================
🛑 COMMENT QUITTER ET COMMENT RELANCER LE LOGICIEL
================================================================================
- POUR QUITTER :
  Fermez simplement la fenêtre noire du Terminal (ou appuyez sur les touches
  Ctrl + C dans celle-ci) et fermez la page de votre navigateur.

- POUR RELANCER PLUS TARD :
  Double-cliquez simplement à nouveau sur "lancer.bat" (Windows) ou
  "lancer.command" (Mac). Tout démarrera instantanément en quelques secondes !

================================================================================
Bonne création vidéo avec Super Video AI !
