# 🎬 Super Video AI — Studio Motion Design & Vidéo IA (Desktop)

Application Desktop native (**Windows & macOS**) permettant de transformer n'importe quel visuel, affiche ou photo en animation **Motion Design 2.5D** ou **Vidéo Cinématographique HD**.

---

## ✨ Fonctionnalités Principales

- 🖥️ **Vraie Application Desktop Native** :
  - Fenêtre logicielle dédiée propulsée par `PyWebView` (WebKit sur macOS, Edge WebView2 sur Windows).
  - **Zéro navigateur web externe**, zéro barre d'adresse, arrêt automatique du moteur à la fermeture de la fenêtre.
  - Boîte de dialogue native **"Enregistrer sous..."** et ouverture directe dans le Finder / Explorateur Windows.
- 🎨 **Double Mode Studio** :
  1. **Mode Motion Design Affiche (2.5D)** : Verrouillage strict des visages et postures (*Statue 2.5D*, *Micro-respiration*, *Micro-regard*), effets d'atmosphère cumulables (reflets trophée, confettis, projecteurs, fumée, brise, étincelles) et mouvements de caméra 2.5D.
  2. **Mode Vidéo Libre Cinéma** : Animation libre par prompt avec presets cinématographiques.
- 📐 **Détection Intelligente des Dimensions (Zéro Rognage)** : Respect intégral du format d'origine (`1:1`, `3:4`, `4:3`, `9:16`, `16:9`).
- 🔔 **Mises à jour automatiques GitHub en 1 clic** intégrées dans l'interface.

---

## 🚀 Lancement Rapide

### 💻 Sur Windows
Double-cliquez simplement sur :
- **`Super Video AI.exe`**

### 🍎 Sur macOS (MacBook / iMac)
Double-cliquez simplement sur :
- **`Super Video AI.app`**

*(Prérequis : Python 3.10+ installé sur la machine. Au premier lancement, l'application configure automatiquement son environnement `.venv` et ses dépendances).*
