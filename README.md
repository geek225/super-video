# 🎬 Super Video AI — Studio Motion Design & Vidéo IA (Desktop)

> **Vibe coder par Stéphane Kevin Assamoi**  
> *Référent Digital & AI Product Builder*

Application Desktop native (**Windows & macOS**) permettant de transformer n'importe quel visuel, affiche ou photo en animation **Motion Design 2.5D** ou **Vidéo Cinématographique HD**.

---

## ✨ Fonctionnalités Principales

- 🖥️ **Vraie Application Desktop 100% Autonome (Méthode A)** :
  - Fenêtre logicielle dédiée propulsée par `PyWebView` (WebKit sur macOS, Edge WebView2 sur Windows).
  - **Zéro prérequis technique** : Si Python ou Git ne sont pas installés sur l'ordinateur de l'utilisateur, l'application télécharge et configure automatiquement son propre moteur portable caché (`.runtime`) lors du premier double-clic.
  - Boîte de dialogue native **"Enregistrer sous..."** et ouverture directe dans le Finder / Explorateur Windows.
- 🎨 **Double Mode Studio** :
  1. **Mode Motion Design Affiche (2.5D)** : Verrouillage strict des visages et postures (*Statue 2.5D*, *Micro-respiration*, *Micro-regard*), effets d'atmosphère cumulables et mouvements de caméra 2.5D.
  2. **Mode Vidéo Libre Cinéma** : Animation libre par prompt avec presets cinématographiques.
- 📐 **Détection Intelligente des Dimensions (Zéro Rognage)** : Respect intégral du format d'origine (`1:1`, `3:4`, `4:3`, `9:16`, `16:9`).
- 🔔 **Mises à jour en 1 clic (même sans Git)** intégrées dans l'interface.
